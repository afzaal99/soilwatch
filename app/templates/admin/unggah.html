Langkah mengambil data

  1. Pilih bulan, lalu salin script Script Google Earth Engine dibuat otomatis untuk bulan yang dipilih.
    Unduh .js
  2. Buka Google Earth Engine dan tempel Buka Code Editor ↗, klik NEW → File di tab Scripts (cukup sekali, berikutnya pakai file yang sama), lalu hapus isi editor (Ctrl+A) dan tempel script (Ctrl+V). Perlu akun Google yang sudah terdaftar di Earth Engine.
  3. Klik Run, lalu periksa ConsolePastikan semua bulan bertanda ✅. Bulan bertanda ⚠️ datanya belum lengkap; ambil lagi nanti.
  4. Jalankan ekspor dan unduh berkasnyaDi tab Tasks, klik RUN lalu RUN lagi di jendela konfirmasi. Setelah selesai (2–10 menit), unduh CSV dari Google Drive folder soilwatch_gee, lalu unggah di kotak sebelah kiri.

Karena curah hujan CHIRPS paling lambat tersedia, data bulan apa pun baru aman diunggah mulai tanggal 25 bulan berikutnya. Contoh: data Oktober aman diunggah mulai 25 November.

Produksi CHIRPS versi 2 dijadwalkan berjalan paralel dengan versi 3 hingga akhir 2026. Jika curah hujan pada berkas kosong, kemungkinan versi 2 sudah dihentikan: sumber curah hujan perlu diganti ke CHIRPS versi 3, seluruh data diekstrak ulang, dan model dilatih ulang.
